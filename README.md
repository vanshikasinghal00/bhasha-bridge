# BhashaBridge 🇮🇳
A multimodal Indian language translation platform powered by AI.

## Features
- **Authentication**: JWT-based Secure Login/Register
- **Text Translation**: Instant translation between 10+ Indian languages
- **Speech-to-Text**: Voice input using Web Speech API
- **Image OCR**: Extract text from images using Tesseract.js
- **History**: Track and search previous translations
- **Favorites**: Bookmark translations for offline/quick access
- **Analytics**: Beautiful dashboard showing usage stats

## Tech Stack
- **Frontend**: React.js, Tailwind CSS, Framer Motion, Chart.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **APIs**: MyMemory API, Web Speech API, Tesseract.js

## Setup Instructions

### 1. Prerequisites
- Node.js (v18+)
- MongoDB (Running locally or on Atlas)

### 2. Backend Setup
```bash
cd server
npm install
cp .env.example .env # Update with your MONGO_URI and JWT_SECRET
npm run dev
```

### 3. Frontend Setup
```bash
cd client
npm install
npm run dev
```

## Folder Structure
- `/client`: React application (Vite)
- `/server`: Express.js backend API
